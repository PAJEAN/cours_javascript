Étape 0 : Mettre en place la page

Casse-briques · étape 0 sur 13 · durée estimée : 30 min à 1 h

Objectif

Créer la page web qui accueillera le jeu : un fichier HTML avec un titre, une zone de dessin (<canvas>) et un script JavaScript relié à la page. À la fin de l'étape, la console affiche un message qui prouve que votre script a bien accès à la zone de dessin.

📖 Dans le cours
  • La création d'une page web : anatomie de la page web (balises, <script>).
  • L'objet console.
  • Le dessin et les canvas : l'élément <canvas>.
  • Les variables : le mot-clé const.

Mise en route

Créez un dossier casse-briques et ouvrez-le dans votre éditeur. Vous y créerez deux fichiers : index.html et game.js.

0.2 La zone de dessin et son style

Le <canvas> est une zone rectangulaire dans laquelle JavaScript dessinera. Sa taille se règle avec les attributs width et height (en pixels), et un id permettra de le retrouver depuis le script. Sans autre réglage, un canvas est invisible : il est transparent et sans bordure. Pour le voir, on le met en forme avec CSS dans une balise <style>.

À toi de jouer. Ajoutez dans le body un canvas de 480 × 320 pixels dont l'id est jeu. Rendez-le visible : fond sombre (#111) et bordure claire. Vous pouvez aussi mettre la page en sombre et centrer le texte.

dans le style : canvas : fond #111, bordure de 2 pixels pleine, couleur claire dans le body, sous le titre : canvas d'identifiant "jeu", largeur 480, hauteur 320
Indice 1

En CSS, les propriétés utiles sont background et border. La taille se règle dans les attributs HTML width et height, pas en CSS : la taille CSS étirerait le dessin au lieu d'agrandir la zone.

Indice 2

Une bordure s'écrit avec trois valeurs : épaisseur, style et couleur, par exemple 2px solid red.

0.3 Le script

Le code JavaScript va dans le fichier game.js. On le relie à la page avec une balise <script src="…">. Cette balise se place à la fin du body : le navigateur lit la page de haut en bas et le script a besoin que le canvas existe déjà quand il s'exécute.

À toi de jouer. Créez un fichier game.js vide à côté de index.html et reliez-le à la page, après le canvas.

à la fin du body, après le canvas : balise script qui charge le fichier "game.js"
Indice

Si la page ne trouve pas le script, la console (F12, onglet Console ou Réseau) affiche une erreur 404 : vérifiez le nom du fichier et son emplacement.

0.4 Le contexte de dessin et la console

Pour dessiner, il faut d'abord récupérer le canvas dans la page, puis lui demander son contexte de rendu 2D : c'est l'objet qui possède toutes les méthodes de dessin. À toi de jouer. Dans game.js :

constante canvas = élément de la page dont l'identifiant est "jeu" constante ctx = contexte de dessin "2d" du canvas afficher dans la console : un message contenant la largeur et la hauteur du canvas afficher dans la console : ctx
Indice 1

Le canvas est un élément de la page comme un autre : on le trouve avec document.getElementById(…). Le contexte s'obtient ensuite avec la méthode getContext du canvas.

Indice 2

La largeur et la hauteur du canvas sont les propriétés canvas.width et canvas.height. console.log accepte plusieurs valeurs séparées par des virgules.

📝 À savoir

ctx est un nom très courant pour « contexte » (context), vous le retrouverez partout. Dans la suite du projet, nous l'utiliserons toujours à la place de canvas.getContext('2d').

Checklist de validation

Ouvrez la page avec Live Server et la console (F12), puis cochez :

  • L'onglet du navigateur affiche « Casse-briques ».
  • Un rectangle sombre avec une bordure est visible sous le titre.
  • La console affiche votre message avec 480 et 320, sans erreur en rouge.
  • La console affiche l'objet CanvasRenderingContext2D.

Erreurs fréquentes

  • Rien ne s'affiche dans la console : le script n'est pas relié (nom du fichier, chemin) ou la page n'a pas été rechargée.
  • Cannot read properties of null : getElementById n'a rien trouvé, souvent parce que l'id est mal orthographié, ou que le script est placé avant le canvas dans la page.
  • getContext is not a function : l'identifiant correspond à un autre élément que le canvas.
  • Le dessin sera déformé plus tard si la taille du canvas est donnée en CSS plutôt que dans width / height.
