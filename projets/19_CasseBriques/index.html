Projet fil rouge : le casse-briques

Au fil de ce projet, vous allez construire un jeu de casse-briques en JavaScript, étape par étape. Chaque étape ajoute une fonctionnalité visible dans le navigateur et vous renvoie vers les parties du cours dont vous avez besoin.

📝 Comment travailler
  • Codez dans l'éditeur de votre choix (VS Code conseillé) et lancez la page avec l'extension Live Server (clic droit sur index.html, Open with Live Server) : elle se recharge automatiquement à chaque enregistrement.
  • Gardez la console du navigateur ouverte (F12) : c'est elle qui vous dit ce qui ne va pas.
  • Dans chaque étape, les sous-étapes sont numérotées (3.1, 3.2…). Le pseudo-code décrit ce qu'il faut faire, pas comment l'écrire : à vous de le traduire en JavaScript.
  • Les indices sont repliés : essayez d'abord seul, puis dépliez-les un par un.
  • Les missions bonus ⭐ sont pour ceux qui ont terminé : elles ne remplacent pas les étapes.
