Anatomie de la page web

  • Une page HTML se compose principalement de deux parties : <head>, qui contient les éléments d'en-tête (titre, métadonnées, liens vers styles ou scripts externes…), et <body>, qui contient le contenu visible de la page.
  • Il existe deux types de commentaires en JavaScript : les commentaires sur une seule ligne // et les commentaires sur plusieurs lignes /* … */.
  • La balise H1 (<h1>) est un élément HTML qui définit généralement le titre principal d'une page web
  • La méthode console.log() permet d'afficher un message dans la console du navigateur (accessible par F12 dans Chrome).
  • En JavaScript, chaque instruction se termine généralement par un point-virgule. Lorsqu'il est omis, l'interpréteur utilise l'ASI (Automatic Semicolon Insertion) pour l'ajouter automatiquement. Attention toutefois : il est recommandé d'ajouter explicitement le point-virgule pour éviter certains comportements inattendus.

L'objet console

L'objet console permet d'interagir avec la console du navigateur pour afficher des informations ou déboguer votre code JavaScript. Elle présente trois méthodes principales :

  • console.log(message) : affiche un message standard dans la console.
  • console.warn(message) : affiche un avertissement, généralement en jaune.
  • console.error(message) : affiche une erreur, généralement en rouge.
