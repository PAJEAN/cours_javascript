Les variables

Une variable est un espace de mémoire qui sert à stocker une information. Elle est identifiée par un nom, qui doit respecter certaines règles :

  • Il peut contenir :
    • des lettres (majuscules ou minuscules),
    • des chiffres,
    • les caractères spéciaux _ et $.
  • Le tiret - est interdit (il est interprété comme une soustraction).
  • D'autres symboles comme * sont aussi interdits.
  • On ne peut pas utiliser les mots réservés du langage (ex. var, if, window...).
  • Les noms de variables sont sensibles à la casse (maVariable et mavariable sont différents).

Déclaration

La phase de création d'une variable est appelée déclaration. Tandis que la phase où une valeur est attribuée à une variable est appelée instanciation. En JavaScript, il existe 3 mots-clés pour déclarer une variable var, let et const.

Les différences entre var, let et const résident dans la portée des variables (fonctionnelle ou bloc), dans leur comportement vis-à-vis du hissage, ainsi que dans la possibilité ou non de réaffecter leur valeur.

📝 À savoir
  • La portée d'une variable est l'ensemble des éléments du code source où la variable existe et est manipulable.
  • Le phénomène de hissage (hoisting en anglais) correspond au mécanisme par lequel JavaScript place certaines déclarations (var, function) en haut de leur portée (scope) avant l'exécution du code. Concernant les variables, il s'agit uniquement de leur déclaration, et non de leur initialisation.

Le mot-clé var

Il permet de déclarer une variable dont la portée est liée à la fonction dans laquelle elle est définie : si elle est déclarée dans une fonction, elle sera accessible dans toute cette fonction, quel que soit le bloc où elle apparaît.

Les variables déclarées avec var sont également hissées en haut de leur portée. Par conséquent, elles sont accessibles mais valent undefined.

Les variables déclarées avec var peuvent être redéclarées.

Le mot-clé var possède une portée limitée à la fonction. Ainsi, lorsqu'une variable est déclarée avec var au sein d'une fonction, sa déclaration est hissée au début de la fonction, et non au niveau du contexte global.

Le mot-clé let

Il permet de déclarer des variables visibles uniquement au sein du bloc d'instructions dans lequel la variable est définie. Un bloc en JavaScript est représenté par les instructions que l'on retrouve entre les accolades e.g. if, while...

Les variables déclarées avec let ne peuvent pas être redéclarées.

Les variables déclarées avec let sont aussi hissées, mais elles restent dans une zone morte temporaire (TDZ) jusqu'à leur initialisation.

Le mot-clé const

Une variable déclarée avec le mot-clé const se comporte de manière similaire à une variable déclarée avec let, à ceci près qu'elle définit une constante accessible uniquement en lecture. Cela ne signifie pas que la valeur stockée est immuable, mais simplement que l'identifiant ne peut pas être réaffecté. De plus, une déclaration const doit toujours être initialisée dès sa création.

Types de variables

Le JavaScript est faiblement typé, c'est-à-dire qu'il autorise une variable à contenir n'importe quel type de données et à en changer en cours d'exécution. L'opérateur typeof permet d'identifier la nature d'une variable.

En JavaScript, tout est objet (ou doit être au moins traité comme tel), excepté pour les primitives. Une primitive est une donnée. Elle n'est pas un objet, ne possède pas de méthode et n'est pas mutable (en d'autres termes, elle ne peut pas être altérée contrairement aux objets). Voici les primitives existantes :

  • undefined par exemple lorsqu'une variable est déclarée sans être initialisée.
  • number englobe différents types de nombres (integer, float, etc.).
  • bigint représente des valeurs plus grandes que celles correctement représentables par une valeur primitive numérique (number).
  • string désignant les chaînes de caractères.
  • boolean pour symboliser les états true et false.
  • null représente la nullité au sens où aucune valeur pour l'objet n'est présente (une variable déclarée peut être instanciée à null). L'opérateur typeof affiche le type object pour une variable instanciée avec le type null (un comportement historique de JavaScript).
  • symbol représente une donnée unique et inchangeable qui peut être utilisée afin de représenter des identifiants pour des propriétés d'un objet.
📝 À savoir

Les enveloppes objet String, Number, Boolean, Symbol et BigInt sont exploités lorsque l'on essaye d'accéder à une propriété ou à une fonction directement à partir d'une primitive.

  • Addition quand les deux opérandes sont numériques.
  • Concaténation quand au moins un des opérandes est une chaîne de caractères.

L'objet Math

L'objet global Math regroupe des constantes et des fonctions mathématiques : Math.PI, Math.abs(x) (valeur absolue), Math.min(a, b, …) et Math.max(a, b, …), Math.floor(x) (arrondi à l'entier inférieur), Math.ceil(x) (supérieur), Math.round(x) (le plus proche), Math.sqrt(x), ou encore Math.random() qui renvoie un nombre décimal aléatoire dans l'intervalle [0 ; 1[.

Les chaînes de caractères

Une chaîne de caractères est une succession ordonnée de caractères. Si elle ne contient aucun caractère, c'est une chaîne vide. Les chaînes de caractères sont des primitives ainsi elles ne sont pas mutables (contrairement à Python par exemple).

Conversion de types

Une chaîne de caractères peut être créee à partir de tout objet JavaScript et de sa méthode de conversion vers une chaîne toString() (possibilité de surcharger cette méthode).

Propriétés et méthodes associées à l'objet String

Une chaîne de caractères exploite les propriétés et les méthodes issues de l'objet String (vous pouvez retrouver l'ensemble des méthodes sur developer.mozilla.org). Pour cela, JavaScript crée un wrapper à partir de l'objet String. Ainsi, lorsque l'on essaye d'accéder à une propritété d'une chaîne de caractères str ou qu'une fonction y est appliquée alors JavaScript réalise l'opération new String(str) afin de créer un objet String initialisé à partir de la valeur de la primitive str. Opérateurs d'égalité == et ===

JavaScript propose deux façons de tester l'égalité entre deux valeurs :

  • == égalité abstraite
  • === égalité stricte

== : l'égalité avec conversion implicite

L'opérateur == compare deux valeurs en essayant d'harmoniser leurs types lorsqu'ils sont différents.

📝 À savoir

L'égalité null == undefined est un cas particulier. Selon la spécification ECMAScript, null n'est égal qu'à deux choses avec == : undefined et lui-même (null).

Lorsqu'un tableau ou un objet est comparé avec ==, JavaScript tente d'abord de le convertir en une valeur primitive. Pour cela, il appelle la méthode toString() (ou valueOf() selon le cas). Ainsi, [1,2].toString() devient "1,2" et peut être comparé à une chaîne, mais aussi être converti ensuite en nombre si l'autre opérande est numérique. En effet, la règle est si l'un des deux opérandes est un nombre et l'autre une chaîne, la chaîne est convertie en nombre.

=== : l'égalité stricte

L'opérateur === compare les deux valeurs sans effectuer de conversion de type. Les deux opérandes doivent donc avoir le même type et la même valeur pour que le test renvoie true.

Par défaut, privilégiez ===, afin d'éviter les pièges liés aux conversions implicites. Réservez == aux cas particuliers où l'on veut volontairement profiter de ses règles de conversion (par exemple, vérifier qu'une valeur est soit null soit undefined en écrivant if (val == null)).
